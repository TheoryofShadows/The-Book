# Findings this volume accepts.
#
# tools/audit.py checks the parsed library against independent chapter and
# verse counts. Every line it reports is either a defect or a property of the
# printed edition, and until this file existed there was no way to tell which:
# the script exited zero whatever it found, so a hundred and fifty lines of
# known-good output hid the real ones. Three chapters of Ignatius and fifty-six
# chapter openings were missing from the volume the whole time it ran.
#
# So: a finding not listed here fails the build. A line listed here that no
# longer occurs also fails the build, because the file has to keep describing
# the volume as it actually is. Nothing regenerates it -- every entry below was
# written down with a reason, which is the standard the rest of the volume is
# held to, and a baseline that rewrote itself would let the next regression in
# under a passing build.
#
# Format: KIND | work | detail | detail. Blank lines and # are ignored.
#
# Regenerate the findings with:
#     python3 tools/audit.py docs/data

# versification difference, not an omission: the WEB ends the chapter at

# Two holes that used to be listed here, and are not holes any more
#
# 1 Clement broke off at chapter 59, because the 1885 Ante-Nicene Fathers
# printing depends on Codex Alexandrinus, whose last leaf is damaged: 57.7
# to 63.4 is not in it, and the great intercessory prayer is inside that.
# The gap was never a gap in the public domain -- Bryennios found the whole
# letter in 1873 and Lightfoot printed it in English in 1891 -- and
# tools/build_lightfoot.py recovers those six chapters from the scan of that
# printing, so the letter now runs to 65 as every edition of the complete
# text does.
#
# Ignatius to the Smyrnaeans had not lost its thirteenth chapter at all. The
# chapter was in the volume, printed as the second half of chapter 12,
# behind the ANF heading that opens it: the single word CONCLUSION, left
# standing in the running text. The boundary is restored.

# ------------------------------------------------------------------------
# Works placed by their section rather than by a dated argument
#
# The arrangement by composition date is the claim this volume exists to
# make, and it is the least examined thing in it. tools/positions.py holds
# 52 records, each carrying a traditional and a critical date with a reason
# and a source for both, and audit.py has always refused to build if any of
# those fields is blank. What it never asked was the other direction:
# whether a work has a record at all. It walked the positions and checked
# them; it never walked the works. So the fifty-two were held to a strict
# standard and the hundred and four were held to none, and nothing counted
# them.
#
# These are not undated on the page. A work with no record inherits the span
# of the section it is filed under -- Micah sits in EIGHTH-CENTURY PROPHETIC
# BOOKS and takes c. 760-700 BCE from the heading -- and the timeline draws
# that bar fainter than a cited one, which is the site saying, correctly,
# that it is a looser claim. What was missing is any accounting of how much
# of the library rests on it: two thirds.
#
# They are listed rather than silenced. Every line here is a work whose
# placement a reader cannot check, and writing a position record for any of
# them removes its line -- which the gate enforces, since an accepted
# finding that stops occurring fails the build just as a new one does. The
# list is meant to shrink.
#
# Not included: the nine entries that carry no text -- editorial notes,
# the Dead Sea Scrolls summaries, and the Psalms of Solomon and Philo
# placeholders. Nothing dates an apparatus note.
